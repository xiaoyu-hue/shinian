## 技术架构

```
时念/
├── index.html              # 单页入口
├── assets/
│   ├── style.css           # 设计令牌（天空引擎输出接口）+ 组件样式
│   ├── sky.js              # 天空引擎：时刻插值、亮度联动、配方切换
│   └── app.js              # 时钟、倒数日 CRUD、localStorage
└── docs/
    ├── PRD.md
    └── PLAN.md
```

- **CSS 变量即天空引擎的输出接口**：`--sky-top / --sky-bottom / --glass-bg / --text` 等由 sky.js 按当前时刻每分钟更新一次
- 代码组织延续主站契约模式：令牌唯一产地、组件规则不定义全局变量
- 选型理由：与作者现有能力同构，AI Agent 迭代效率最高，且为 v0.5 Capacitor 封装做好准备（Capacitor 以静态网页为输入）
