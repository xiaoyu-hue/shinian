## 1. 背景

### 1.1 为什么做

作者希望拥有一个「自己做的、真正安装在手机系统里的 App」。当前全部作品（个人主站、sonder520、Nymir、XY 系列）均为网页形态，虽有移动端适配，但没有一件真正进入手机系统。

### 1.2 硬约束

| 约束 | 说明 |
|---|---|
| 零成本 | 开发、构建、分发全链路免费：GitHub Actions 免费额度 + GitHub Releases |
| 零后端 | 不部署任何服务器；数据全部本地存储；天气采用免密钥的 Open-Meteo 客户端直连 |
| 零备案 | 不走国内应用商店上架（软著/备案成本远超开发本身） |
| 仅安卓 | iOS 需要 Apple 开发者账号（$99/年）与 macOS，明确不做 |

### 1.3 已完成的调研结论（2026-10-04，全部实证核实）

| 外部依赖 | 结论 |
|---|---|
| [Open-Meteo](https://open-meteo.com) | 免费天气 API，**无需密钥、无需服务器**，客户端直连；含日出日落时刻。已实测调用成功 |
| [@capacitor/local-notifications](https://www.npmjs.com/package/@capacitor/local-notifications) v8.3.1 | 本地通知（喝水/倒数日提醒），不依赖推送服务器。已核实 |
| [lunar-javascript](https://github.com/6tail/lunar-javascript)（1692★，MIT） | 二十四节气、农历计算，驱动季节切换的「中文逻辑」时间轴。已核实 |
| 天空背景现成开源方案 | **不存在**可复用的高星项目（GitHub 同类全为 0 星玩具）→ 核心视觉自研，成为本产品最大原创点 |
| Capacitor + GitHub Actions 打包 APK | 官方支持，runner 预装安卓 SDK，免费额度内可完成 |

## 2. 目标与非目标

### 目标（Goals）

- **G1 心愿达成**：产出一个可安装在安卓手机桌面、有独立图标与启动画面的真实 App
- **G2 路线验证**：走通「网页技能 → Capacitor 封装 → CI 云端打包 → Releases 分发」全链路，沉淀零成本移动化方法论
- **G3 作品表达**：将主站的液态玻璃视觉体系升级为「随时间流动」的形态，形成设计签名
- **G4 日用留存**：作者自己把《时念》设为手机浏览器主页（后续为 App），三天后仍在用——这是最终验收标准

### 非目标（Non-Goals）

- ❌ 上架 Play Store 或国内应用商店（试水期sideload安装即可）
- ❌ iOS 版本
- ❌ 账号体系、云同步、社交功能
- ❌ 采集任何用户数据（隐私承诺，见 NFR-3）

## 4. 视觉体系（核心设计）

### 4.1 三层天空引擎

季节 × 时段若两两手工组合 = 4 × 7 = 28 套配色，不可行。采用**分层叠加**架构：

| 层 | 职责 | 构成 | 数量 |
|---|---|---|---|
| **底层 · 时刻层** | 决定天空基础渐变（视觉大头） | 黎明 / 清晨 / 正午 / 午后 / 日落 / 暮色 / 夜，七时段色阶，分钟级连续插值 | 7 套 |
| **中层 · 季节层** | 色相与饱和度轻量滤镜 | 春（樱粉暖调）/ 夏（青蓝通透）/ 秋（琥珀金）/ 冬（青灰冷调） | 4 套 |
| **顶层 · 夜间装饰** | 夜晚专属氛围 | 星空（常态）；极光（冬季深夜彩蛋） | 2 种 |

总工作量 13 组参数，覆盖 28 种组合。

### 4.2 液态玻璃：舞台，而非主角

- 与主站相比，App 内玻璃**更薄、更透**：透明度更高、模糊半径更小、阴影更弱——天空必须透出来
- 玻璃配方跟随天空亮度自动切换：白天亮天空 → 磨砂白玻璃 + 深色文字；夜晚 → 深海暗玻璃 + 浅色文字；切换平滑过渡，禁止突变闪跳

### 4.3 对比度守护（可读性红线）

- 色阶定义阶段即为每个时段配对「天空色 + 玻璃配方 + 文字色」三件套
- 正文对比度 ≥ WCAG AA（4.5:1），大字标题 ≥ 3:1
- 插值只在同一配方区间内进行；跨配方切换用短过渡动画

## 6. 非功能需求

| 编号 | 类别 | 需求 |
|---|---|---|
| NFR-1 | 零依赖 | 访客端无框架、无外部请求（v0.1）；构建无 node_modules |
| NFR-2 | 性能 | 毛玻璃自动降级（帧率不足减层，主站已验证机制移植）；天空重绘 ≤ 1 次/分钟；夜间装饰可关 |
| NFR-3 | 隐私 | v0.1 零网络请求、零数据采集；数据仅存设备本地；此承诺写入应用说明 |
| NFR-4 | 兼容 | Chrome/Safari 近两年版本；360-430px 竖屏优先，桌面居中收窄适配 |
| NFR-5 | 无障碍 | 尊重 prefers-reduced-motion；文字对比度见 4.3 |

## 7. 风险与对策

| 风险 | 影响 | 对策 |
|---|---|---|
| 亮色天空下玻璃卡可读性不足 | 核心体验受损 | 三件套逐时段配对 + WCAG 校验前置到定义阶段；真机实测强制 |
| 低端安卓毛玻璃掉帧 | 卡顿、耗电 | 帧率监测自动降级（主站已验证机制移植） |
| 范围蔓延 | 烂尾 | 严格按 v0.1 清单执行；新想法一律进 backlog |
| 天空配色「自然直觉」因人而异 | 审美反复 | 七时段以现实摄影色卡为锚点；作者逐时段验收拍板 |
